# Реализация v1 (ненормативный рабочий файл)

База: `restore/verified-691-tests`; рабочая ветка: `dev/v1-completion`.
Нормативные документы прочитаны полностью 2026-11-07; не изменены.

## Сделано и локально проверено

- ТЗ §3,18,23; политика §5–6: два постоянных сервиса, приватный runtime,
  worker без SQLite/.env, нет автозапуска/namespace/offline/egress fallback.
- ТЗ §4–6,23.4; политика §1–4,11: локальный URL, единый диспетчер, JSON Lines
  ≤64 КиБ, peer UID, сохранённые карточки, реальные доступные варианты или ровно
  две fallback-кнопки. Реальный inspect написан, без сетевого запуска в этой среде.
- ТЗ §7–10,13,15; политика §4,7: один download, ограниченные параллельные inspect,
  единая политика форматов, MP4/MP3, проверка duration/размера/кодеков/полный decode,
  отмена группы, тайм-ауты, дисковый допуск и FIFO с пропуском без сброса времени.
- ТЗ §6,10–12,17: SQLite только бот, идемпотентность updates/callback,
  UTC-квота, антиспам, кэш, независимая доставка.
- ТЗ §9,12,14,16; политика §8: local/cloud без fallback, file_id, устойчивые
  попытки/расписания, SHA-256/манифест готового файла, оба режима хранения,
  восстановление по status перед повторным download, очистка только после
  подтверждённого прекращения worker. Результаты, сохранённые при true, не
  удаляются после последующей смены настройки.
- ТЗ §17,19,22: Backup API/ротация/проверка, сохранение повреждённой базы и
  запрет её неявной пустой замены, CLI/блокировки/подтверждения, миграция данных
  без удаления исходных таблиц и файлов, инструкции установки/обновления/отката.
- Локально: Debian 13.6, Python 3.13.5, FFmpeg 7.1.5; 82 тест PASS,
  зависимости/doctor PASS. Полный протокол — `docs/VALIDATION.md`.

## Не завершена внешняя приёмка (INCONCLUSIVE)

ТЗ §21,24; политика §10: постоянные systemd/cgroup-BPF, реальный loopback baseline
и отказ worker/детей, DNS/HTTPS под фильтром, Fake-IP Debian 12, реальные платформы,
оба режима Telegram и рестарты полного цикла. Контейнер не предоставляет VPS с
systemd; токен и Local Bot API не подключены. Ни одна из этих проверок не объявлена PASS.
Сервис не объявлен готовым к публичному запуску.

Исторический кэш/старые локальные результаты сохранены, но неоднозначные старые
параметры не подменяются новыми. Перенос нужно проверить на обезличенной копии
реальной базы; новые записи v1 сохраняются между дальнейшими обновлениями.
