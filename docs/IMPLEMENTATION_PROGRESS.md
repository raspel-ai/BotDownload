## Исходные расхождения

Автозапуск offline-worker из bot.main; SQLite в worker_ipc/reservations/controllers;
старый протокол op/token/reserve; альтернативные namespace/egress/offline execution
paths; прямой metadata из Telegram; неполная проверка пути URL; нет рабочего
fallback видео/аудио; нет двух штатных юнитов. Старые тесты фиксируют эти пути.
